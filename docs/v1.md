# v1 — Naive backend port (done)

Port tinylama's GPU inference into hippo_leap with a compile-time backend
abstraction and OpenAI-compatible HTTP server.

## What shipped

- GGUF loader, CPU tensor ops, Q2_K/Q3_K/Q6_K dequantization
- SentencePiece tokenizer with chat template support
- Naive GPU backend: all kernels ported verbatim from tinylama
  - Quantized GEMV (Q2_K, Q3_K, Q6_K), fused KV and gate+up+SiLU variants
  - Float32 GEMV (decode) and GEMM (prefill)
  - RMSNorm, fused residual+RMSNorm, RoPE, attention, embedding
- Compile-time backend switch (`-d:backendNaive`)
- OpenAI-compatible HTTP API via mummy + openai_leap types
- Lock-based single-inference concurrency
- Full test suite: unit (CPU), integration (GPU golden output), e2e (HTTP)

## Verified on

- Strix Halo (gfx1151): golden output matches tinylama reference
- TinyLlama 1.1B Q2_K model

## Known limitations

- Only Q2_K, Q3_K, Q6_K quant formats supported
- No streaming responses
- Single inference at a time (global lock)
- `-d:zippyNoSimd` workaround for hipcc + zippy SSE conflict
- Only tested with TinyLlama architecture

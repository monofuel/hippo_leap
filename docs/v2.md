# v2 — Broader model support (done)

Run real-world models beyond TinyLlama.

## What shipped

- Q4_K and Q8_0 quantization support (CPU dequant + GPU GEMV kernels)
- Llama 3.2 1B Instruct support (Q4_K_M, Q8_0)
- BPE tokenizer (GPT-2 style) alongside existing SentencePiece
- Llama 3 chat template formatting
- GQA with different head count ratios
- RoPE frequency base from GGUF metadata
- Fused GPU kernels: KV projection, gate+up+SiLU, RoPE+KV store
- Tiled online-softmax attention (removed 2048 context cap)
- GPU argmax (eliminates logits download)
- Integration tests with Llama 3.2 1B golden output
- Benchmarks: 35.7 tok/s on Strix Halo (see docs/benchmarks.md)

## Not done (descoped)

- Q5_K quantization — not needed for current models
- Performance target of "within 80% of llama.cpp" — at 17%, requires
  architectural changes beyond the naive backend's scope (see
  docs/wmma-experiment-and-specialized-backend.md for analysis)

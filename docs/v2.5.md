# v2.5 — Responses API and conversation support

Add the OpenAI Responses API endpoint and improve conversation handling so
the server is usable with standard clients.

## Tasks

### Full message history in chat completions
- Concatenate all messages (system, user, assistant) into the prompt
- Apply the model's chat template to format each role correctly
- Respect system message as system prompt
- This makes multi-turn conversations work without client workarounds

### Responses API (`POST /v1/responses`)
- openai_leap already has full type definitions (`CreateResponseReq`,
  `OpenAiResponse`, `ResponseInput`, `ResponseOutput`, etc.)
- Map `input` messages to the same internal prompt format as chat completions
- Return `OpenAiResponse` with `output` containing `ResponseOutput` items
- Handle `instructions` field as system prompt
- Handle `max_output_tokens` for generation limit
- Return proper `ResponseUsage` (input_tokens, output_tokens, total_tokens)

### Responses API fields to support initially
- `input` (message array with text content)
- `model` (echo back)
- `instructions` (system prompt)
- `max_output_tokens`
- `temperature` (if sampling is implemented)
- `stream` (reject with error, same as chat completions)

### Fields to defer
- `tools` / `tool_choice` — requires function calling
- `previous_response_id` — requires session state
- `prompt_cache_key` — requires prompt caching
- `reasoning` — requires reasoning model support
- `background` — requires async job queue

### Prompt caching (KV cache reuse)
- Track the last prompt's token prefix per session
- On new request, find the longest matching prefix in the KV cache
- Only run prefill on the new suffix tokens
- Massive speedup for multi-turn conversations (avoid re-prefilling the
  entire conversation each turn)
- Requires session/conversation tracking (by request ID or custom header)

## Success criteria

- Multi-turn chat completions work correctly with standard OpenAI clients
- Responses API returns valid `OpenAiResponse` objects
- Prompt caching gives measurable speedup on second+ turns
